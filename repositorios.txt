# Repositorios del proyecto SmartLogix
# IMPORTANTE: reemplazar los placeholders por los enlaces reales de GitHub antes de subir a Blackboard.

Repositorio principal:
https://github.com/USUARIO-O-ORGANIZACION/smartlogix-fullstack-3
Descripción: Monorepo con frontend React, BFF Spring Boot, microservicios, arquetipos Maven y documentación de evaluación.

Frontend React:
https://github.com/USUARIO-O-ORGANIZACION/smartlogix-frontend
Descripción: Aplicación React empaquetada como componente NPM. Incluye pages, components, hooks, services/api.js, pruebas unitarias y configuración de coverage.

Backend For Frontend - BFF:
https://github.com/USUARIO-O-ORGANIZACION/smartlogix-bff
Descripción: Servicio Spring Boot que funciona como BFF/API Gateway, agrega dashboard y expone proxy único para inventario, pedidos y envíos.

Microservicio Inventario:
https://github.com/USUARIO-O-ORGANIZACION/smartlogix-ms-inventario
Descripción: Microservicio Spring Boot para productos, stock, SKU, CRUD y reducción de inventario.

Microservicio Pedidos:
https://github.com/USUARIO-O-ORGANIZACION/smartlogix-ms-pedidos
Descripción: Microservicio Spring Boot para creación y cambio de estado de pedidos. Implementa Factory Method y Circuit Breaker manual hacia inventario.

Microservicio Envíos:
https://github.com/USUARIO-O-ORGANIZACION/smartlogix-ms-envios
Descripción: Microservicio Spring Boot para gestión de envíos, generación de código de seguimiento y actualización de estados.

Arquetipos Maven:
https://github.com/USUARIO-O-ORGANIZACION/smartlogix-arquetipos-maven
Descripción: Arquetipos Maven base para generar nuevos microservicios y nuevos BFF con estructura coherente del proyecto.
